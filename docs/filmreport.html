Introduction

New York City has long been a central hub for the film and television industry. From major motion pictures to episodic television shows, filming has become a routine part of daily life in the city, with production crews frequently occupying streets, sidewalks, and public spaces. Given the scale and visibility of this activity, our group set out to examine whether film production activity can act as an early signal for rising real estate values in New York City neighborhoods.

My specific contribution to this broader research question focuses on whether certain communities are systematically left out of filming, particularly lower-income neighborhoods. Examining this relationship is a critical first step in understanding whether film production reflects existing economic conditions or has the potential to identify neighborhoods before significant real estate changes occur. If lower-income communities are routinely excluded from filming, then film production may simply mirror current economic inequality and established real estate patterns. In that case, filming activity would be more reflective of present conditions rather than predictive of future neighborhood change.

To explore this question, I analyzed the relationship between neighborhood median household income and filming activity at the ZIP-code level.

# Helper to try one URL and return success TRUE/FALSE
safe_download <- function(url, dest) {
  status <- tryCatch(
    download.file(url, destfile = dest, mode = "wb", quiet = TRUE),
    error = function(e) 1L
  )
  is.numeric(status) && status == 0L
}
# ---- Function to download one file ----
download_one_file <- function(year, borough) {
  # pick correct borough slug for the filename
  borough_slug <- borough
  if (borough == "statenisland" && year >= 2020) {
    borough_slug <- "staten_island"   # 2020+ files use underscore
  }
  # older years = .xls, newer years = .xlsx
  if (year <= 2017) {
    exts <- c("xls", "xlsx")
  } else {
    exts <- c("xlsx", "xls")
  }
  for (ext in exts) {
    url  <- sprintf("%s/%d/%d_%s.%s", base_url, year, year, borough_slug, ext)
    dest <- file.path(data_dir, sprintf("%d_%s.%s", year, borough_slug, ext))

    message("Trying: ", url)

    if (safe_download(url, dest)) {
      message("  ✓ downloaded: ", dest)
      return(dest)
    } else {
      message("  ✗ failed for: ", url)
    }
  }
  warning("Could not download file for ", year, " / ", borough)
  NA_character_
}

sales_list <- lapply(files, function(f) {
  # read everything as text, no column names yet
  raw <- read_excel(
    path      = f,
    col_names = FALSE,
    col_types = "text"
  )
  # find the row that contains the real header ("BOROUGH ...")
  header_row <- which(raw[[1]] == "BOROUGH")
  if (length(header_row) == 0L) {
    header_row <- which(grepl("BOROUGH", raw[[1]]))[1]
  }
  if (is.na(header_row)) {
    stop("Could not find header row in file: ", f)
  }
  # use that row as column names, data starts on the next row
  header <- as.character(unlist(raw[header_row, ]))
  df <- raw[(header_row + 1):nrow(raw), ]
  names(df) <- header
  # drop completely empty rows/cols
  df <- df %>%
    remove_empty("rows") %>%
    remove_empty("cols")
  # add year from file name (e.g. "2019_bronx.xlsx")
  name <- basename(f)
  year <- as.numeric(substr(name, 1, 4))
  df$year <- year
  df
})

clean_2018_2019 <- function(df) {

  df %>%
    clean_names() %>%
    # Merge duplicate columns
    mutate(
      borough_code_raw = coalesce(borough, borough_2, borough_3),
      neighborhood_raw = coalesce(neighborhood, neighborhood_2, neighborhood_3),
      address_raw      = coalesce(address, address_2, address_3),
      zip_code_raw     = coalesce(zip_code, zip_code_2, zip_code_3),
      sale_price_raw   = coalesce(sale_price, sale_price_2, sale_price_3),
      sale_date_raw    = coalesce(sale_date, sale_date_2, sale_date_3)
    ) %>%
    # Borough code -> name
    mutate(
      borough_code_raw = trimws(borough_code_raw),
      borough = case_when(
        borough_code_raw == "1" ~ "Manhattan",
        borough_code_raw == "2" ~ "Bronx",
        borough_code_raw == "3" ~ "Brooklyn",
        borough_code_raw == "4" ~ "Queens",
        borough_code_raw == "5" ~ "Staten Island",
        TRUE ~ NA_character_
      )
    ) %>%
    filter(!is.na(borough)) %>%
    # Clean price
    mutate(
      sale_price = suppressWarnings(as.numeric(gsub("[^0-9]", "", sale_price_raw)))
    ) %>%
    # ---- Robust date parsing ----
    mutate(
      # Try numeric Excel serial first
      sale_date_num = suppressWarnings(as.numeric(sale_date_raw)),
      date_from_num = suppressWarnings(as.Date(sale_date_num, origin = "1899-12-30")),
      # Try character dates (mdy, ymd)
      date_from_char = suppressWarnings(parse_date_time(sale_date_raw, orders = c("mdy", "ymd"))),
      # Final date = numeric first, otherwise character-parsed
      sale_date = coalesce(date_from_num, date_from_char)
    ) %>%
    
    filter(!is.na(sale_price), sale_price > 10000, !is.na(sale_date)) %>%
    transmute(
      year,
      borough,
      neighborhood = neighborhood_raw,
      address      = address_raw,
      zip_code     = zip_code_raw,
      sale_price,
      sale_date
    ) %>%
    arrange(year, borough, sale_date)
}

get_acs_all_years <- function(variable, geography="zcta",
                              start_year=2013, end_year=2023){
  fname <- glue("{variable}_{geography}_{start_year}_{end_year}.csv")
  fname <- file.path("data", "finalproject", fname)
  
  if(!file.exists(fname)){
    YEARS <- seq(start_year, end_year)
    YEARS <- YEARS[YEARS != 2020] # Drop 2020 - No survey (covid)
    
    ALL_DATA <- map(YEARS, function(yy){
      tidycensus::get_acs(geography, variable, year=yy, survey="acs5") |>
        mutate(year=yy) |>
        select(-moe, -variable) |>
        rename(!!variable := estimate)
    }) |> bind_rows()
    
    write_csv(ALL_DATA, fname)
  }
  
  read_csv(fname, show_col_types=FALSE)
}

The results show a positive and statistically meaningful relationship between income and filming. A Pearson correlation of 0.23 (p < 0.001) indicates that higher-income ZIP codes tend to receive more filming permits. A linear regression confirms this pattern: each additional $10,000 in median household income is associated with approximately eight additional filming permits per year (p < 0.001). While income explains a modest share of the overall variation in filming activity (R² = 0.053), the direction and consistency of the relationship suggest that lower-income communities are underrepresented in filming relative to higher-income communities. Although filming occurs across all boroughs and income levels, wealthier neighborhoods tend to experience both more frequent filming and a higher total number of permits over time.

The small number of ZIP codes and limited filming events make patterns harder to detect, but the data indicate that Staten Island is largely overlooked by the film industry regardless of income level.

Across all five boroughs, higher-income ZIP codes are generally more likely to host filming and to do so more frequently, though the strength of this pattern varies. Manhattan and Brooklyn show the clearest income-based disparities, while Queens displays a weaker relationship and the Bronx and Staten Island experience low filming activity overall. Taken together, these borough-level patterns reinforce the conclusion that lower-income communities are systematically underrepresented in New York City’s filming landscape.

Conclusion

Asking whether certain communities are systematically left out of filming—particularly lower-income neighborhoods—helps establish an essential baseline for evaluating whether film production activity can act as an early signal of rising real estate values in New York City. If filming were evenly distributed across neighborhoods regardless of income, film permits would provide little insight into future housing market changes. However, the data show that filming activity is not random. Instead, it is concentrated in higher-income ZIP codes and occurs much less frequently in lower-income areas.

Understanding this uneven distribution is crucial because it helps distinguish cause from correlation. If film production consistently avoids lower-income neighborhoods, then high levels of filming may simply reflect existing wealth rather than predict future growth. In this case, filming activity would follow real estate value increases instead of leading them. Without first identifying which communities are excluded from filming, it would be easy to misinterpret film permits as a predictive signal when they are actually responding to established market conditions.

At the same time, the analysis also shows that filming does occur across all boroughs, even if unevenly. In boroughs such as Queens and Brooklyn, some lower-income ZIP codes still receive moderate filming activity. These cases are especially important for future research. If filming begins to appear in historically underrepresented or lower-income areas and is followed by rising rents or property values, that pattern could suggest that film production is identifying neighborhoods with future growth potential—perhaps due to unique physical characteristics, improving infrastructure, or increasing cultural visibility.

This analysis highlights an important limitation as well: income alone does not fully explain filming activity. Factors such as zoning, industrial land use, neighborhood aesthetics, permitting logistics, and community receptiveness likely play meaningful roles. Future research could strengthen these findings by incorporating land-use data, historical property values, or time-lagged housing outcomes to better assess whether filming precedes or follows real estate change.

Overall, by first examining whether lower-income communities are systematically excluded from filming, this analysis clarifies when and where film permits can plausibly serve as a leading indicator. Film production is most likely to signal future real estate change in neighborhoods where filming expands beyond traditionally high-income areas. Without this foundational understanding, it would be impossible to determine whether film activity is driving neighborhood change or merely reflecting existing economic inequality.

Limitations

While this analysis provides valuable insight into the relationship between neighborhood income and filming activity in New York City, several limitations should be acknowledged.

First, the analysis relies on ZIP codes as a proxy for neighborhoods. ZIP codes are designed for mail delivery rather than for capturing social or economic boundaries, and they can contain a mix of income levels, housing types, and land uses. As a result, some within-ZIP variation in income or filming activity may be obscured. Using smaller geographic units, such as census tracts, could provide a more precise picture of how filming relates to neighborhood-level economic conditions.

Second, the analysis focuses primarily on median household income as the key explanatory variable. While income is an important indicator of neighborhood economic status, it does not fully capture other factors that may influence filming decisions. Variables such as zoning regulations, availability of industrial or commercial space, street layout, proximity to studios, and neighborhood infrastructure likely play an important role. Because these factors are not included in the current analysis, the results should not be interpreted as income being the sole driver of filming activity.

Third, the study examines associations rather than causal relationships. Although higher-income ZIP codes tend to receive more filming permits, this analysis cannot determine whether income causes increased filming or whether both are driven by underlying neighborhood characteristics. Similarly, while filming activity may be related to real estate trends, this study does not establish whether filming precedes changes in property values or simply follows them.

Finally, filming permit data captures approved filming events, but it may not fully reflect informal production activity, short-term shoots, or variations in the scale of productions. A large studio production and a small independent shoot are treated equally in the permit data, even though their economic and social impacts may differ substantially.

Future Research

Future research could build on this analysis in several meaningful ways. One important extension would be to examine the timing of filming activity relative to changes in real estate values. By incorporating time-lagged housing data—such as rent growth, sale prices, or building permits—researchers could assess whether increases in filming activity tend to occur before, during, or after changes in neighborhood real estate markets. This would help clarify whether filming acts as an early signal of neighborhood change or simply reflects existing trends.

Another promising direction would be to incorporate additional neighborhood characteristics, such as zoning classifications, land use patterns, or commercial density. Including these variables could help disentangle whether filming is driven by economic status, physical space availability, or regulatory factors. In particular, identifying the role of industrial and mixed-use areas could shed light on why some lower-income ZIP codes still attract filming activity.

Future work could also explore borough-specific dynamics in greater depth, including how local permitting practices, infrastructure, or community engagement influence filming decisions. Comparing New York City to other major filming hubs could further contextualize whether the observed patterns are unique to NYC or common across cities with large film industries.

Finally, qualitative research—such as interviews with location scouts, production managers, or community organizations—could complement the quantitative findings. These perspectives could provide insight into how filming locations are chosen and how residents experience the presence or absence of film production in their neighborhoods.

Together, these extensions would deepen our understanding of how film production interacts with urban development and housing markets, and would help determine whether filming activity can serve as a meaningful early indicator of neighborhood change.
